# 深信服售后技术支持 Agent

面向深信服售后技术支持场景的智能 Agent：**设备配置自动化备份与智能管理** + **软件更新信息获取与升级建议** + **知识库分层检索与沉淀**。基于深信服官方 REST API 文档与技术支持平台公开资料构建，同时支持华为/H3C/锐捷网络设备的 AI 对话管理。

## 核心功能

**功能一：设备配置自动化备份与智能管理**

- **自动备份**：结构化配置快照（网络对象/自定义服务/接口/静态路由/NAT/ACL/用户绑定全量，可解析/可视化/可恢复，支持导出可读 JSON 供第三方设备迁移）+ 配置文件归档（SHA256 校验）；手动/定时/变更前自动触发

- **配置可视化**：设备状态、网络接口与实时流量、安全区域、NAT/访问控制策略、IP-MAC 绑定、静态路由、网络对象、自定义服务、黑白名单；任意两份快照字段级 diff

- **自然语言管理**：对话查询/修改接口、NAT、访问控制、用户绑定、黑白名单等——所有变更经确认卡片人工确认后下发，执行前自动安全备份，全程审计

- **配置体检**：确定性规则引擎识别规则冲突（遮蔽/矛盾）、空策略、过宽权限、高危端口暴露、资源异常（含 mbuf，关联 AF 8.0.85 已知问题），支持一键修复

- **备份报告生成**：一键生成包含配置可视化、配置体检报告、软件更新建议的完整 HTML 报告，支持离线查看

**工程可靠性**

- **设备可达性保护**：登录锁按设备隔离、登录独立超时（8s）、失败负缓存（10s 冷却）——一台不可达设备不再拖死整站，错误快速友好返回
- **对话连续性**：会话按设备归属，切换菜单/设备后历史（含工具轨迹、待确认卡片）自动恢复；一键新会话（设备信息与长期记忆自动带入）
- **数据真实**：平台返回的 0-1 比例使用率自动修正为百分比；虚拟机使用率接监控接口真实值；重复工具调用自动合并
- **失败快速收敛**：写工具生成变更计划失败后终止同工具重试（防止模型变参数无限循环），失败原因如实反馈用户
- **响应优化**：纯查询免技能路由前置调用、历史工具结果截断（多轮对话 prompt 不膨胀）、设备版本探测 TTL 缓存、记忆提取降频合并、知识库问答超时收敛（`KB_ASK_TIMEOUT` 等，默认 45s）+ SSO 会话预热、升级信息缓存过期后台刷新——慢设备与多轮对话场景首字与总耗时显著下降

**知识问答分层检索（未勾选知识库也生效）**

- 设备功能作用、故障排查、版本特性、配置方法、原理类提问**自动触发**（意图识别覆盖 70+ 关键词模式），无需手动勾选
- 检索顺序：**本地个人知识库优先**（SQLite 分词加权评分，毫秒级）→ 本地未命中或信息不足时**官方知识库兜底**（效果同勾选「查询知识库」，回答附官方引用）
- 命中率优化：中文 2-gram 分词 + 多字段加权评分（主题×5 / 别名·标签×4 / 摘要×2 / 正文×1），不同措辞也能召回；词条携带同义别名（aliases）参与检索
- 自动沉淀口径：路由到官方知识库且实际取得返回（含澄清反问）时，对话结束**自动沉淀本轮问答**（仅本轮提问 + 知识库返回 + 本轮回答，不带入之前的会话）；本地知识库命中不触发沉淀

**功能二：软件更新信息与升级建议**

- **多源抓取**：深信服技术支持平台版本发布说明免认证按版本精确抓取（AF/AC 两条产品线，真实条目优先、内置知识库兜底，来源标注透明）；软件下载列表支持 `.env` 配置登录 Cookie 抓取；官网 PSIRT 安全公告（公开）

- **升级建议**：升级路线图（AF 8.0.48 为旧架构末端，跨架构到新架构 8.0.69+ 需客服评估 + 重装系统盘；AC 11.0+ 可直升稳定版 13.0.121，需前置检测）、PSIRT 命中检测、EOL 识别、关键变更点四类归类（新增功能/安全修复/已知问题修复/优化，以官方『新版本发布信息』页真实版本为准）、升级时机与行动清单（跨架构自动分段）

**功能三：官方知识库对话（查询知识库）**

- AI 对话页勾选「查询知识库」后，Agent 通过 `skills/zhuge-ai-assistant` 技能接入深信服官方诸葛智能知识库（社区 BBS SSO 登录 + WebSocket 实时问答）
- 按当前设备产品线（AF/AC）定向检索，回答附带官方引用来源；服务不可用时明确降级提示，不编造
- 社区账号密码在『平台设置』配置（界面 > .env），保存即生效；未配置时相关功能明确提示需先配置（代码中不内置任何账号）

**功能四：个人知识库（LLM WIKI）**

- 勾选过知识库的对话自动经 LLM 提炼为结构化知识词条（LLM-Wiki 式：原子主题 + 固定骨架 + 同义别名 + 交叉引用）；官方知识库命中自动沉淀本轮问答，不带入之前的会话内容
- 自动去重合并：精确同主题刷新、相似主题自动合并（要点/标签/引用/别名并集，产品线隔离防误合），避免重复沉淀
- 检索命中率：中文 2-gram 分词 + 加权评分（主题×5 / 别名·标签×4 / 摘要×2 / 正文×1）+ 同义别名参与匹配，换措辞查询也能召回；未命中时建议换核心词重试
- 对话沉淀：说「把这个问题记录到知识库」即可登记沉淀（不依赖知识库勾选）
- 链接沉淀：给出网页链接并要求「录入/沉淀到知识库」，Agent 抓取页面内容提炼为词条，引用附带来源链接；深信服案例库链接（support.sangfor.com.cn/cases/...）经 `sangfor-support-crawler` 技能（复用 BBS 社区账号 SSO 认证）精准读取案例全文，权限不足时明确提示案例所需身份
- ECharts 可视化：知识图谱（词条节点 + 归一化标签连边）、分类分布、沉淀时间线；待沉淀对话支持勾选沉淀/忽略，并实时展示沉淀进度（排队/提炼中/完成条数/跳过原因）
- 链接录入结果透明：内容与已有词条同主题时明确列出被合并更新的词条；词条列表支持「最近创建/最近更新」排序
- 反思与总结：支持自定义沉淀日期范围，生成「阶段总结 / 知识盲区 / 待验证结论 / 学习建议」报告（可删除）

**工具技能化（Skill）**

- 60 个工具（深信服 50 + 网络设备 10）按运维场景组织为 9 个技能（网络设备运维/状态巡检/配置查询/配置体检与修复/备份恢复/策略变更/升级建议/设备接入/知识库检索），按需注入；所有设备类工具支持 devices 参数跨设备/批量操作
- 只读工具全量可用、写工具按技能收窄；关键词路由零延迟离线可用，LLM 按技能目录兜底选择，未命中回退全量模式

**功能五：SCP 云计算平台接入（只读）**

- 新增第三种设备类型 SCP（纳管 HCI 节点）：添加设备只需平台地址 + AccessKey/SecretKey（EC2 AK/SK 签名认证，只读查询）
- AI 对话：集群状态（计算/存储资源）、平台版本、物理机及网口功能 IP、虚拟机及其网卡端口组详情
- 配置可视化：平台概况（版本/部署模式/主机与虚拟机统计/资源进度条）、集群、物理机、虚拟机（点行看详情抽屉）、存储
- 配置备份：结构化快照（物理机网口功能 IP、虚拟机 IP 与网卡、桥接网卡端口组），支持 diff 对比
- 配置体检：集群/物理机/虚拟机/存储资源阈值（建议带实际值与剩余余量，引用业界容量标准 ≤80%/预留 20~30%/N+1）、物理机 CPU/内存分配超分（业界 5:1/1.5:1）、单机 ≥90% rightsizing 升配建议、僵尸虚拟机
- 备份报告：SCP 专属章节（版本/集群资源/物理机/虚拟机/网口功能 IP/桥接端口组/存储 + 体检，数据标注备份时点）
- 更新建议：SCP 与 HCI 双产品线（官方『新版本发布信息』页锚定），软件列表含下载地址与 MD5
- 数据真实：0-1 比例使用率自动修正；虚拟机使用率接监控接口真实值（列表接口恒 0）；OS 型号码解码（如 l2664 → Linux 2.6.64）

**功能六：网络设备 AI 对话（华为/H3C/锐捷）**

- AI 对话直接管理已添加的交换机/路由器（SSH）：配置查询、健康状态（CPU/内存/温度）、路由表、接口概览与详情、ARP 表项、故障日志分析定位、终端定位（IP/MAC→接入交换机+端口，复用拓扑采集的 ARP/MAC 表）
- 配置下发（接口配置、静态路由、VLAN 等）自动进入系统/接口视图，走统一确认卡片，默认不保存配置（save=true 持久化）；特殊命令可用任意命令执行兜底
- 仅支持华为(VRP)/H3C(Comware)/锐捷(RGSOS)；其他厂家提示到「网络设备管理」页批量执行/控制台
- 跨设备批量：所有设备类工具支持 devices 参数（设备名/IP 列表），深信服设备批量查询逐台聚合、批量变更合并为一张确认卡片确认后逐台下发

**功能七：企业微信机器人渠道（移动端对话）**

- 基于企微智能机器人官方 **WebSocket 长连接**（`wecom-aibot` 协议，仅 BotID + Secret，无需公网 IP/回调加密）：在企业微信 App 内单聊机器人即可使用全部 AI 对话能力
- 渠道无关网关层（`channel_gateway`）：发送方绑定会话与设备、白名单、管理指令（设备列表/切换设备/新会话/帮助，支持自然语言表达如「开个新会话」「切换到总部AF」，疑问句不误判），编排器/护栏/工具/记忆零改动复用
- **会话自动管理**：默认为全局模式（对话覆盖全部已添加设备，可点名设备或说"所有设备"批量操作；「切换设备 全局」可回到全局），超过 `CHANNEL_SESSION_TIMEOUT_MINUTES`（默认 30 分钟，0=关闭）未对话自动开启新会话并回到全局模式；超过 `CHANNEL_SESSION_TIMEOUT_MINUTES`（默认 30 分钟，0=关闭）未对话，下次消息自动开启新会话并提示；「切换设备」与「新会话」指令均强制开启新会话，对话日志按会话/设备独立成条、归属清晰
- **渠道与 Web 同能力**：写操作在企微内即可完成确认（`CHANNEL_READONLY_MODE=true` 可整体关闭渠道写入口引导回 Web）；「确认/取消」文本指令支持裸确认（自动定位当前会话最近待确认动作）与带单号两种写法，且**跨渠道兼容**——Web 端生成的确认卡片可在企微回复「确认 <ID>」执行
- 待确认变更可收到**按钮交互卡片**，点击确认/拒绝即执行并回推结果；长回复自动分段，含 30s 心跳断线自动重连
- 管理指令增强：切换设备支持只给 IP（自动匹配管理地址），设备列表标注只读设备，切换到只读设备时明确提示
- 配置见 `.env`（`WECOM_AIBOT_ENABLED/ID/SECRET` 等）；`GET /api/channel/wecom/status` 可查连接状态，`POST /api/channel/message` 为渠道联调入口

## 快速开始

### 环境要求

- Python 3.10-3.14（开发用 3.12，CI 矩阵覆盖 3.12/3.13/3.14）、Node.js 18+

### 启动方式（按推荐顺序）

**方式一：Agent 技能启动（推荐）**

本仓库内置 [windows-quickstart](skills/windows-quickstart/SKILL.md) 技能。在常见 Agent 软件（ZCode / Claude Code / Cursor 等）中打开本项目，让 Agent 加载该技能即可：自动检测并安装 Python 与 Node.js（经 winget）、创建虚拟环境、安装前后端依赖、生成 .env 并启动服务、健康检查验证——**全新 Windows 电脑全程零手动排障**。也可不经过 Agent 直接运行引导脚本：

```powershell
powershell -ExecutionPolicy Bypass -File skills\windows-quickstart\scripts\setup_windows.ps1 -Mirror
```

**方式二：一键启动脚本**

```bat
:: Windows
scripts\start_all.bat
```

自动完成：创建 venv → 检查并补装依赖 → 生成 .env → 分离进程启动前后端（无多余命令窗口）→ 打开浏览器。

**方式三：服务管理控制台（可自定义监听 IP/端口）**

```bat
:: Windows
python scripts\launcher.py
```

图形化界面：一键启动/停止/重启、自定义**后端/前端的监听 IP 与端口**（保存后同步到 `vite.config.js` 代理目标）、恢复默认配置。

**手动启动：**

```bash
# 后端（首次先安装依赖并配置 .env）
cd backend
python -m venv ../.venv && ../.venv/Scripts/python -m pip install -r requirements.txt   # Linux: ../.venv/bin/pip
copy .env.example .env   # 填入 LLM_API_KEY（智谱/DeepSeek 等 OpenAI 兼容接口均可）
../.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8600

# 前端
# （后端须单进程运行：uvicorn 默认 --workers 1，请勿调大——取消信号/设备客户端缓存/
#  保活等状态均为进程内单例，多 worker 会导致取消失效与重复登录）
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 ，默认为**全局模式**（覆盖全部已添加设备）：可直接点名任意设备提问，或在侧栏「目标设备」切换（全局 / 深信服设备 / 网络设备分组列出）。对话日志默认全局视角，可按设备（含全局会话与网络设备）筛选。

### 真实设备兼容

**AF 防火墙**（实测 AF 8.0.45.380）：
适配层内置针对真实设备的兼容处理：旧密码套件 TLS（SECLEVEL=0）、`/api/v1` 路径、`items` 响应与 `uuid` 字段映射、action 枚举实测校准（0=拒绝/1=允许）、API 并发会话复用（按设备缓存登录客户端）、可选端点优雅降级、版本探测 TTL 缓存。**写操作兼容层**：ACL（应用控制策略）下发自动翻译为设备原生格式（以设备当前规则为基底仅覆盖变更字段），引用的 IP组/服务不存在时自动创建（裸 IP/网段→同名网络对象，端口如 TCP5211→同名自定义服务），"任意地址"自动规范为内置网络对象「全部」。接入后即可完成状态/配置可视化/体检/备份/升级建议与经确认的自然语言变更。

**AC 上网行为管理**（实测 AC 12.0.40）：
使用开放接口（HTTP 端口 9999），md5 共享密钥签名认证。覆盖在线用户、网络策略、流控策略、IP/MAC 绑定等数据采集。

### LLM 配置（可选）

未配置 Key 时自动进入**离线兜底模式**（支持状态/接口/NAT/ACL/绑定/体检/备份/升级建议等固定意图查询），核心功能可完整演示。配置后获得完整自然语言对话与变更能力：

除 `.env` 外，也可直接在界面左下角「**平台设置 → 大模型（LLM）接入**」填写 API 地址 / Key / 模型（任意 OpenAI 兼容接口），**保存即生效无需重启**：

```ini
# backend/.env 方式（智谱 GLM 示例）
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_API_KEY=your-key
LLM_MODEL=glm-4-flash
# DeepSeek 示例：LLM_BASE_URL=https://api.deepseek.com/v1  LLM_MODEL=deepseek-chat
```

### 企业微信机器人渠道（可选）

在企业微信管理后台创建**智能机器人**（开启「API 模式 → 长连接」，建议由超级管理员创建以保证 userid 明文），将 BotID 与 Secret 写入 `backend/.env` 重启后端，即可在企微 App 内单聊机器人对话：

```ini
WECOM_AIBOT_ENABLED=true
WECOM_AIBOT_ID=你的机器人ID
WECOM_AIBOT_SECRET=你的机器人Secret
WECOM_ALLOWED_USERS=          # 可选，逗号分隔 userid 白名单，留空允许全部企微成员
CHANNEL_READONLY_MODE=false   # 渠道只读开关（默认 false 渠道可写）；置 true 时企微写操作引导回 Web 确认
CHANNEL_SESSION_TIMEOUT_MINUTES=30  # 会话超时（分钟），超时后自动开启新会话，0=关闭
KB_ASK_TIMEOUT=45             # 诸葛知识库单次问答总超时秒数（另有 KB_CLARIFY_GRACE/KB_POLL_INTERVAL）
```

### 接入真实设备

前端「+ 添加设备」→ 选择设备类型（AF 防火墙 / AC 上网行为管理 / SCP 云计算平台）→ 填设备地址与凭据。建议先用只读模式评估。网络设备（交换机/路由器）在「网络设备管理」页添加（SSH）。

## 启动管理工具（Launch GUI）

系统提供图形化服务管理工具 `scripts/launcher.py`（基于 Python tkinter），运行 `python scripts\launcher.py` 即可打开：

| 功能 | 说明 |
|------|------|
| 服务状态监控 | 实时显示后端/前端运行状态（● 运行中 / ○ 启动中 / ○ 已停止），URL 可点击打开 |
| 一键操作 | 启动全部 / 停止全部 / 重启全部 / 打开前端 |
| 监听配置 | 修改后端绑定 IP、后端端口、前端端口，自动同步到 `vite.config.js` 代理目标 |

## 安全设计

- 写操作强制**两阶段确认**（变更计划卡片 → 人工确认 → 执行），执行前自动生成回滚备份
- 敏感操作黑名单（恢复出厂/删管理员/关 HA/清空配置）先于 LLM 拦截
- 全局/设备级只读模式；全部工具调用与确认落审计日志
- 升级固件只建议不代执行；LLM 只基于工具返回数据作答，防幻觉
- 高危操作（删除操作、涉及 445/3389/22 等端口、任意地址到 untrust 区域）需二次确认
- 架构迁移警告：AF 旧架构先升级至末端 8.0.48，跨架构到新架构（8.0.69+）需客服评估并重装系统盘，报告与行动清单明确分段提示
