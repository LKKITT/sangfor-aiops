# 深信服售后技术支持 Agent — 演示脚本

> 建议演示时长 8~10 分钟，按用例递进。启动方式见 README「快速开始」。
> 全部用例可离线运行（内置模拟器 + 内置版本知识库）；配置 LLM Key 后对话更自然。

## 准备（1 分钟）
1. 双击 `scripts/start_all.bat`（或分别启动后端/前端）。
2. 浏览器打开 http://localhost:5173 ，确认左侧选中「演示-AF模拟器」设备。

## 用例 1：设备状态总览（30 秒）
- 页面「配置可视化」→ 设备状态：版本 8.0.85、CPU/内存/磁盘/mbuf 进度条、会话数。
- **话术**：Agent 通过官方 REST API 实时读取设备状态中心，mbuf 76% 已被标注为异常水位（对应 AF 8.0.85 已知问题，后面升级建议会呼应）。

## 用例 2：配置可视化（1 分钟）
- 「网络接口」页签：接口表 + 实时流量柱状图（eth1 电信出口流量最大）。
- 「访问控制策略」页签：9 条策略，指出 acl-003（禁止财务区）与 acl-001（允许内网全部上网）的顺序问题——为体检环节埋伏笔。
- 「网络对象」「自定义服务」页签：策略引用的对象（财务网段/服务器区网段）与服务（Web服务/DNS服务）——备份/恢复与体检均覆盖这两个配置层。

## 用例 3：AI 对话查询（1 分钟）
- 「AI 对话」发送：`看看 NAT 策略`
- 展示流式输出 + 工具调用芯片（查询 NAT ✓）+ Markdown 表格。
- 再发送：`看一下设备状态`

## 用例 4：配置体检（2 分钟）★核心
- 「配置体检」→ 点击「运行配置体检」。
- 得分 2/100：高危 4（acl-003 deny 被 acl-001 allow 覆盖导致财务管控失效、445/RDP 对公网暴露、mbuf 超阈值）、中危 5、低危 4。
- **话术**：确定性规则引擎（CIDR 包含/服务集合运算），不是大模型"感觉"，每一条都有证据与建议；部分风险支持一键修复。

## 用例 5：对话式变更 + 确认卡片（2 分钟）★核心亮点
- 回到对话发送：`把445端口对公网暴露的策略停用`
- Agent 定位 acl-004 → 弹出**变更确认卡片**（变更前后对照 + 风险提示）。
- 先点「拒绝」→ Agent 礼貌接受；再发送一次 → 点「确认执行」→ 执行回执。
- 切到「配置可视化」→ 访问控制策略：acl-004 已停用。
- **话术**：所有写操作强制人工在环，执行前自动生成安全备份，全程审计。

## 用例 6：自动备份与快照对比（1.5 分钟）
- 对话发送：`立即创建一次备份`，或备份页点「立即备份」。
- 「备份与恢复」页：时间线出现新备份（含配置文件归档 + SHA256）。
- 快照对比面板自动展示最近两份差异（acl-004 enabled 变化可见）。
- 点「导出快照 JSON」：得到可读的结构化配置文件（对象/服务/路由/策略/绑定全量 + 引用关系），**设备意外故障时可作为向第三方设备迁移的依据**；`.conf` 私有格式归档另存。

## 用例 7：两阶段恢复（1 分钟）
- 备份页选较早的备份 →「恢复此备份」→ 弹窗展示恢复计划（删除/修改/重建明细）→「确认恢复」。
- 完成后刷新：acl-004 恢复启用；时间线多一条「恢复前安全备份」。

## 用例 8：软件更新建议（1.5 分钟）★核心
- 「软件更新建议」页：
  - 结论：建议在近期维护窗口升级（8.0.85 → 8.0.107），路径 8.0.95→8.0.106→8.0.107；
  - 理由：mbuf 已知问题触发（呼应用例 1 的 76% 水位）；
  - 关键变更点分类：新增功能 4 / 已知问题修复 4 / 优化 2；
  - 时机与前置条件、行动清单（第 1 步可由 Agent 代办）。
- 点击「刷新官方更新信息」：展示官方平台认证状态与降级机制（正文需深信服客户认证，未配置 Cookie 自动降级公开源+内置知识库，来源透明）。
- 页面底部「官方软件更新列表」：AF（product_id=13）/ AC（product_id=22）两条产品线；左下角「平台设置」粘贴登录 Cookie 后点「重新抓取」即可拉取认证内容，未配置时明确提示降级原因。

## 用例 9：对话升级咨询（30 秒）
- 对话发送：`有新版本可以升级吗？` Agent 基于工具数据回答并强调业务中断与低峰窗口。

## 用例 10：安全护栏（30 秒）
- 对话发送：`帮我恢复出厂设置` → 直接被拦截（黑名单先于大模型）。
- （可选）`.env` 设 `READONLY_MODE=true` 重启后，任何变更请求都被拒绝。

## 用例 11：官方发布说明免认证抓取（30 秒）
- 「软件更新建议」页的关键变更点已来自官方平台**免认证抓取的真实条目**（如 AF 8.0.107「应用控制策略支持基于 mac 管控」「URL 防护支持 DoT/DoH 识别」等），每个版本标注数据来源（official_platform / builtin_snapshot）。
- 左下角「平台设置」：深信服平台 Cookie（抓取软件下载列表等认证内容）与大模型接入（任意 OpenAI 兼容接口，保存即生效）均可视化配置。

## 用例 11b：接入真实设备（口述 30 秒）
- 「+ 添加设备」→ 真实设备 → 填 AF 管理地址与 API 账号 → 勾选**只读模式** → 测试连通。
- 已在 AF 8.0.45.380 真机实测：状态/接口/NAT/ACL/路由/体检/备份（含配置文件归档）/升级建议（正确提示旧架构需售后迁移）全链路只读可用；写操作被只读护栏 403 拦截。
- 同一套适配层代码，模拟器/真实设备无缝切换。

## 用例 12：测试与工程质量（口述 30 秒）
- `python -m pytest -q`：38 个测试全部通过（分析引擎/适配器/备份恢复闭环/升级建议/护栏）。
- 设计文档 `docs/design.md`：架构、选型、流程、模块、测试验证方式完整成文。
