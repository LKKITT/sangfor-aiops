# 深信服售后技术支持 Agent

面向深信服售后技术支持场景的智能 Agent：**设备配置自动化备份与智能管理** + **软件更新信息获取与升级建议** + **双知识库与设备记忆**。基于深信服官方 REST API 文档（api/ 目录留存完整拆分文档）与技术支持平台公开资料构建，内置与官方 API 同构的 AF 模拟器，可离线完整演示。

- **三类设备统一纳管**：AF 防火墙（官方 REST API）、AC 上网行为管理（开放接口）、SCP 云计算平台（EC2 AK/SK 签名，只读），同一套适配层代码，模拟器/真实设备无缝切换
- **49 个 Agent 工具、8 个场景技能**：按设备类型过滤注入（AF 可见 42 / AC 25 / SCP 30），写权限按技能收窄
- **40 项确定性体检规则**：CIDR 数学判定，结论稳定可解释，不依赖大模型"感觉"
- **112 个自动化测试用例**（backend/tests，12 个文件），全链路不依赖真实设备与网络

## 核心功能

### 功能一：设备配置自动化备份与智能管理（AF / AC / SCP）

- **自动备份**：结构化配置快照（网络对象/自定义服务/接口/静态路由/NAT/ACL/用户绑定全量，可解析/可视化/可恢复，支持导出可读 JSON 供第三方设备迁移参照与审计存档）+ 配置文件归档（SHA256 校验，真实设备端点不可用时自动降级为仅快照备份并如实记录）；手动/定时（默认每日 02:00，可配）/变更前自动三种触发
- **配置可视化**：AF——设备状态、网络接口（合并实时链路状态与流量）、安全区域、NAT/访问控制策略、IP-MAC 绑定、静态路由、网络对象、自定义服务、黑白名单；AC——在线用户、上网策略、流控策略、流量排行、吞吐量、绑定；SCP——平台概况、集群、物理机、虚拟机（详情抽屉）、存储；任意两份快照字段级 diff，另支持"备份 vs 设备当前配置"diff
- **自然语言管理**：对话查询/修改接口、NAT、访问控制、用户绑定、黑白名单、网络对象、自定义服务等——所有变更经确认卡片人工确认后下发（支持在卡片上直接编辑参数），执行前自动安全备份，全程审计
- **配置体检**：确定性规则引擎 40 个检查项（规则遮蔽/矛盾/重复、空策略、过宽权限、高危端口暴露、资源异常含 mbuf、绑定与路由、对象与服务，SCP 资源阈值/超分/僵尸 VM），评分 = 100 − 高危15/中危6/低危2，支持结构化修复计划一键修复
- **备份报告生成**：一键生成自包含离线 HTML 报告（配置可视化 + 体检 + 升级建议，SCP 专属章节）

### 功能二：软件更新信息获取与升级建议

- **多源抓取与缓存**：官方『新版本发布信息』页免认证按版本精确解析（AF/AC/SCP/HCI 四条产品线）+ 软件下载列表（.env 配置 Cookie 抓取）+ 官网 PSIRT 安全公告（公开）+ 内置版本知识库兜底；结果统一落 SQLite 缓存并标注来源（official_platform / builtin_snapshot）；每日 03:30 自动刷新（可配），支持手动强刷
- **升级建议引擎**（确定性核心 + LLM 解说）：升级路线图（AF 8.0.48 为旧架构末端，跨架构到 8.0.69+ 需客服评估 + 重装系统盘，行动清单自动分段；AC 12.x 直达稳定版 13.0.121 需前置检测）、PSIRT 命中检测、EOL 识别、关键变更四类归类（新增功能/安全修复/已知问题修复/优化）、升级时机与行动清单（第一步"立即备份"可由 Agent 代办）

### 功能三：官方知识库对话（查询知识库）

- AI 对话页勾选「查询知识库」后，Agent 通过 `skills/zhuge-ai-assistant` 技能接入深信服官方诸葛智能知识库（社区 BBS SSO 登录 + WebSocket 实时问答）
- 按当前设备产品线（AF/AC）定向检索，回答附带官方引用来源（markdown 链接原样呈现）；服务不可用时明确降级提示，不编造
- 社区账号密码在『平台设置』配置（界面 > `ZHUGE_BBS_USERNAME/PASSWORD` 环境变量），保存即生效；JWT 会话缓存复用（约 7 天）

### 功能四：个人知识库（LLM WIKI）

- **三条沉淀路径**：勾选过知识库的对话自动经 LLM 提炼为结构化词条（主题/分类/摘要/要点/步骤/官方引用/标签，增量提取只取本轮勾选后的内容）；对话说「把这个问题记录到知识库」（record_to_kb，走确认卡片）；给出网页链接并要求「录入/沉淀到知识库」（ingest_url_to_kb 抓取提炼，引用附带来源链接）
- 词条按主题去重更新；ECharts 可视化：知识图谱（词条节点 + 归一化标签连边）、分类分布、沉淀时间线；待沉淀对话支持勾选沉淀/忽略
- 反思与总结：自定义日期范围生成「阶段总结 / 知识盲区 / 待验证结论 / 学习建议」报告（可删除）

### 工具技能化（Skill）

- 49 个工具按运维场景组织为 8 个技能（状态巡检/配置查询/体检修复/备份恢复/策略变更/升级建议/设备接入/知识库检索），按需注入
- 只读工具全量可用、写工具按技能收窄；record_to_kb / ingest_url_to_kb 在任意技能下常开（沉淀是用户明确动作）；关键词路由零延迟离线可用，LLM 按技能目录兜底选择（16 token、2.5s 超时，不占工具轮次上限），未命中回退全量模式

### 设备记忆（跨会话）

- **长期记忆**（memory_items，按设备隔离，四类：事实/用户偏好/操作记录/设备上下文）：每轮注入最近 15 条；对话结束后台提取（全会话 ≥6 条消息触发，两次小调用生成摘要与事实，前缀去重，保留上限 50 条）
- **短期记忆**（conv_summaries，会话摘要）：随对话滚动更新，每轮注入；历史消息拉取上限 24 条

### 工程可靠性

- **设备可达性保护**：登录锁按设备隔离、登录独立超时（8s，可配）、失败负缓存（10s 冷却）——一台不可达设备不再拖死整站
- **对话连续性**：会话按设备归属，切换菜单/设备后历史（含工具轨迹、待确认卡片）自动恢复；一键新会话（设备信息与长期记忆自动带入）；欢迎语与快捷提问按 AF/AC/SCP 三套差异化
- **防重复与防重试**：同参数重复工具调用直接合并复用结果；写工具失败后终止同工具重试（防止模型变参无限重试）
- **数据真实**：平台返回的 0-1 比例使用率自动修正为百分比；SCP 虚拟机使用率接监控接口真实值（列表接口恒 0）；OS 型号码解码（如 l2664 → Linux 2.6.64）

## 快速开始

### 环境要求

- Python 3.10+（开发用 3.12）、Node.js 18+；Windows/Linux 均可

### 一键启动（推荐）

```bat
:: Windows
scripts\start_all.bat
```

自动完成：创建 venv → 检查并补装依赖（backend/requirements.txt 为唯一事实源）→ 生成 .env → 分离进程启动前后端（无多余命令窗口）→ 打开浏览器。

### 服务管理控制台（可自定义监听 IP/端口）

```bat
python scripts\launcher.py
```

图形化界面（tkinter）：一键启动/停止/重启、打开前端、实时状态监控（3 秒刷新，显示 PID 与可点击 URL）、监听配置（后端 IP/端口、**前端 IP/端口**，保存后自动同步 `vite.config.js` 代理目标）、恢复默认（127.0.0.1:8600 + 5173）、退出保护（关闭时询问是否停止服务）。

### 手动启动

```bash
# 后端（首次先安装依赖并配置 .env）
cd backend
python -m venv ../.venv && ../.venv/Scripts/python -m pip install -r requirements.txt   # Linux: ../.venv/bin/pip
copy .env.example .env   # 填入 LLM_API_KEY（智谱/DeepSeek 等 OpenAI 兼容接口均可）
../.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8600

# 前端
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 ，默认已连接「演示-AF模拟器」设备。模拟器同时挂载在后端 `/simulator` 路径，可从设备视角直接调试。

### LLM 配置（可选）

未配置 Key 时自动进入**离线兜底模式**（支持状态/接口/网络对象/自定义服务/NAT/ACL/绑定/体检/备份/升级建议 10 类固定意图），核心功能可完整演示。配置后获得完整自然语言对话与变更能力。

```ini
# backend/.env（智谱 GLM 示例）
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_API_KEY=your-key
LLM_MODEL=glm-4-flash
# DeepSeek 示例：LLM_BASE_URL=https://api.deepseek.com/v1  LLM_MODEL=deepseek-chat
```

也可在界面左下角「**平台设置 → 大模型（LLM）接入**」填写 API 地址 / Key / 模型（任意 OpenAI 兼容接口），**保存即生效无需重启**（界面配置优先于 .env）。

### 接入真实设备

前端「+ 添加设备」→ 选择设备类型（AF 防火墙 / AC 上网行为管理 / SCP 云计算平台）→ 真实设备 → 填设备地址与凭据（AC 只填 IP 自动构造 `http://{ip}:9999`；SCP 填平台地址 + AccessKey/SecretKey）。适配层与模拟器同构，同一套代码无缝切换。**建议先用只读模式评估**。

**AF 防火墙**（实测 AF 8.0.45.380）：适配层内置 8 项真机兼容处理——旧密码套件 TLS（SECLEVEL=0）、`/api/v1` 路径前缀、`items` 响应与 `uuid` 字段映射、策略 action 枚举实测校准（0=拒绝、1=允许）、无聚合状态端点逐项降级、按设备缓存登录客户端（规避 API 并发会话限制）、可选端点失败降级并记录 capability_gaps、系统预置对象跳过未引用检查。接入即可完成状态/可视化/体检/备份/升级建议全链路。

**AC 上网行为管理**（实测 AC 12.0.40）：开放接口（HTTP 端口 9999），md5 共享密钥签名认证；覆盖在线用户、上网策略、流控策略、IP/MAC 绑定、流量排行、吞吐量等采集；空响应/非 JSON/单对象返回自动兼容。

## 安全设计

- 写操作强制**两阶段确认**（变更计划卡片 → 人工确认 → 执行，卡片支持编辑参数），执行前自动生成 pre_change 回滚备份
- 敏感操作黑名单（恢复出厂/删管理员/关 HA/清空配置）**先于 LLM 拦截**；恢复出厂、管理员、HA、固件等敏感资源未开放任何 Agent 工具（能力层不可达）
- 全局只读模式（`READONLY_MODE=true`）/ 设备级只读开关；全部工具调用、确认与执行落审计日志
- 高危操作（删除、涉及 445/3389/22 等端口、any 到 untrust）二次确认；升级固件只建议不代执行（升级代执行正则拦截）
- LLM 只基于工具返回数据作答，防幻觉；官方平台认证内容不破解不绕过，未配置 Cookie 明确降级
- 凭据全部环境变量化或本地存储，git 历史已清洗（无硬编码密钥）
- 架构迁移警告：AF 旧架构先升级至末端 8.0.48，跨架构（8.0.69+）需客服评估并重装系统盘，报告与行动清单分段提示
